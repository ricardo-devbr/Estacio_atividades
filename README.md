# Atividades Práticas - Estácio 🎓

Este Repositório foi criado para concentrar e organizar os projetos e atividades práticas desenvolvidas ao longo da minha jornada acadêmica na Estácio.

## 📁 Organização do Repositório

Abaixo estão descritos os projetos contidos neste repositório e o foco de aprendizado de cada um:

### [sabor_rapido_app]
* **Descrição:**
  ## Protótipo de interface gráfica de app de pedidos
  contem um dicionario com nome e valor dos itens do menu
  labels e botoes que executam acoes quando o usuario interage
  Treeview com os itens do menu, botar de adicionar novo item ao cardapio,
  visualizar pedido e finalizar pedido que mostra os itens do pedido e o valor total do pedido ##

### 👥 [agenda_de_contatos]
* **Descrição:**
  ## Sistema simples de contatos para salvar, 
  editar e excluir informações com base no ID via terminal utilizando banco de dados ##

### 🎓 [cadastro_de_alunos]
* **Descrição:**
  ## Sistema acadêmico simples para registro e listagem de estudantes.
  além de fazer operacoes para informar se o aluno está aprovado, reprovado
  ou em recuperacao, nesse projeto foi utilizado pandas de forma breve para criar
  uma planilha Excel com as informações do banco de dados ##

### 📦 [cadastro_produtos](./cadastro_produtos)
* **Descrição:**
  ## Sistema para controle de produtos
  com interface gráfica, botoes e execução de açoes do usuario,
  alem de utilizar a geracao de dados aleatorio para usar como teste.
  É possivel atualizar, cadastrar excluir produto, além de limpar os campos de texto.

----

* **Tecnologias utilizadas nas atividades:** PostgreSQL, Python, Tkinter e pandas.
* **O que aprendi:** *criacao de interface gráfica, funcoes e operacões de banco de dados.*
